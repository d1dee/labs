Your computer lab,

Labs FCD is a dashboard for managing school computer labs. It sits between your network and the machines students use, giving you one place to control internet access, block distractions, and keep every lab ready for class.

Get Started See Features

Running a school computer lab means shared machines, rotating classes, and the occasional exam. One period needs internet for research. The next needs it turned off. A practical exam is coming up and you need every machine in the same clean state. Labs FCD is built for that rhythm.

What you can do

Three tools that handle the most common tasks in a school computer lab.

Internet Control

Turn internet on or off for an entire lab or a single machine. Block YouTube across Lab 2 with one click, then unblock it when the lesson needs it. No more students browsing during the wrong hours.

  • Toggle per lab or per device from one view
  • See which labs are online at a glance
  • Enable or disable in seconds, not minutes

Firewall & Domain Blocking

Block exact domains like login.live.com or use regex patterns to catch whole categories. The firewall integrates with Pi-hole for DNS-level blocking, so restrictions work before the browser even loads the page.

Lab Management

Format machines back to a clean image. Clear user data. Add OS-level restrictions like disabling USB storage or hiding the control panel. And when it's exam time, switch the whole lab to Exam Mode.

Exam Mode

One switch locks the entire lab down. Only the applications and sites needed for the test are available. Everything else is blocked.

"It's 8:15 AM. Form 3 has a practical exam in Lab 1 at 9. You switch the lab to Exam Mode, push the clean image to all 40 machines, and disable USB storage. Done before the bell rings."

  • Reimage computers to a clean state via FOG
  • Clear user data between sessions
  • Disable USB, hide control panel, and other OS restrictions

How it works

Three steps from setup to daily use.

1

Connect your labs

Point Labs FCD at your MikroTik router, Pi-hole instance, and FOG server. Add each lab with its subnet and DHCP server.

2

Set your rules

Choose which domains to block, which labs need internet, and what restrictions apply. Set it once and adjust anytime.

3

Manage from one dashboard

Toggle access, block sites, and manage machines from one screen. Everything you need is in one place.
